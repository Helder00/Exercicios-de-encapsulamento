# Exercicios-de-encapsulamento
Este repositório contém a resolução da Avaliação III da cadeira de Programação Orientada a Objetos.

Estrutura do Projeto
O projeto foi desenvolvido no Eclipse IDE e está organizado em 4 pacotes principais:
- `exercicio1`: Classe `CarroCorrida` e testes de funcionamento.
- `exercicio2`: Classe `Elevador` com controlo de capacidade e andares.
- `exercicio3`: Classe `Agenda` para armazenamento de até 10 contactos.
- `exercicio4`: Classes `Televisao` e `ControleRemoto`.
